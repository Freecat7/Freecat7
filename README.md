### invoicelite

[invoicelite](https://github.com/Freecat7/invoicelite) is self-hosted invoicing for
German businesses, in a single Docker container. I built it because I did not want to
pay a subscription for my own invoices or keep assembling them in Word, and the German
e-invoicing mandate was going to end that anyway.

- XRechnung 3.0.2 and ZUGFeRD, validated against the official KoSIT validator
- The §19 and §13b tax regimes, recorded per document rather than globally
- GoBD: approved documents are locked, numbering stays gapless
- Income-surplus statement (EÜR) as PDF and CSV for the tax advisor

The interface and documents are German, because the software encodes German law.
